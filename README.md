# harshdaiya.com — Personal Website

The official personal portfolio and digital space of **Harsh Daiya** — Staff Software Engineer at PayPal (Risk Platform), Fintech Author, Angel Investor, ADPList Mentor, and Explorer.

Website: [harshdaiya.com](https://harshdaiya.com)

---

## 🌟 Key Features

- **Monumental Editorial Typography**: High-impact editorial design inspired by Awwwards Site of the Year nominees, featuring `clamp()` typography, metallic shiny reflections, and integrated interactive iconography.
- **Real-Time Live Telemetry**: Live status telemetry with Chicago, IL local time, system load, pipeline latency, and commerce protection metrics.
- **Interactive Risk Engine Simulator**: Interactive real-time pipeline simulator illustrating how high-velocity transaction streams are evaluated, enriched with feature stores, and decided in sub-25ms latency.
- **Interactive 25 Visited US States Atlas**: Dynamic vector SVG map of the United States highlighting the 25 states visited by Harsh, complete with national park highlights, roadtrip notes, and filtering.
- **Embedded Interactive Terminal (`hd-cli`)**: Realistic in-browser terminal console supporting commands like `help`, `bio`, `role`, `skills`, `book`, `travel`, `matrix`, and `sudo hire` 🎉.
- **Command Palette (`⌘K` / `Ctrl+K`)**: Instant Spotlight-style keyboard search and jump navigation across all sections, links, and theme actions.
- **Interactive AI Assistant Pill & Drawer**: Embedded conversational assistant answering questions about Harsh's role at PayPal, published book, core skills, and mentorship.
- **ThemeAware Click Sparks**: Interactive particle burst canvas on click.
- **Integrated Scheduling & Contact**: Direct Google Calendar appointment scheduler (`Chat with Harsh`), and direct contact form with Botpoison anti-spam defense.
- **Peer-Reviewed Research Showcase**: Dedicated publications section featuring 4 papers cited 56+ times across international journals and IEEE conferences, linked directly to Harsh's verified Google Scholar profile.
- **AI & Agentic Competency Matrix**: In-depth coverage of autonomous agents, LangChain, LangGraph, RAG architectures, and Vector Databases (Pinecone, Milvus, ChromaDB) alongside distributed risk engines.
- **Synthesized Web Audio FX**: Tactile sound design powered natively by the Web Audio API (with convenient mute toggle).
- **100/100 Lighthouse Performance**: Pure semantic HTML5, modern CSS3 variables, and vanilla ES6 with 0ms build overhead and instant GitHub Pages deployment.

---

## 🛠️ Architecture

- `index.html`: Semantic HTML5 application entry point with OpenGraph tags, JSON-LD structured data, and accessible markup.
- `css/modern.css`: Comprehensive design system with CSS custom properties for Dark/Light themes, glassmorphism, responsive grid layouts, and typography.
- `js/modern.js`: Interactive engine powering telemetry, particle simulation, vector maps, command palette, audio synthesis, and terminal console.
- `CNAME`: Configured for custom domain `harshdaiya.com`.
